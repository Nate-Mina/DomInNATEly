## ⚡ Highlights & Features

- **🎬 Dual Platform Integration**:
  - **YouTube Video Engine**: Official YouTube Iframe API player embedded for HD music video viewing.
  - **Suno AI Catalogue**: All 57 official Suno tracks with original 9:16 portrait video streams, CloudFront high-fidelity audio, and full multi-verse song lyrics.
- **🔄 Bidirectional Playback Synchronization**:
  - The sticky bottom audio player's seek scrubber, live `mm:ss` timestamp indicators, volume slider, and mute toggles are fully synchronized in real-time with the desktop showcase player.
  - Seeking on the bottom scrubber immediately navigates the active video player.
- **🎙️ Immersive Right-Hand Stage**:
  - **Video Mode**: Interactive video playback with high-resolution scaling.
  - **Lyrics Mode**: Formatted full song lyrics viewer with verse/chorus breakdowns.
  - **Art Mode**: Album artwork with ambient pulsing glows and animated equalizers.
  - **Size Toggles**: Compact (S), Medium (M), and Large (L) staging controls.
- **🔍 Fast Search & Filter Hub**:
  - Instant client-side search across titles, artists, lyrics, and genres.
  - Category filters: Rock, Remix, Acoustic, Anthem, Duet, Alt.
  - Multi-criteria sorting: Playlist Order, Track Title, Duration (Shortest to Longest / Longest to Shortest).
  - Grid View & Compact List View toggle.
- **⌨️ Global Keyboard Controls**:
  - `Space`: Play / Pause toggle.
  - `←` / `↑`: Previous track.
  - `→` / `↓`: Next track.
- **📱 Responsive & Cross-Device**:
  - Desktop XL showcase stage with sticky navigation.
  - Mobile bottom audio bar with expandable queue drawer and floating video modal.
  - Dark mode and Light mode with localStorage persistence.
- **🔗 Social Sharing & Discovery**:
  - Direct share cards for every single song (X/Twitter, Facebook, Reddit, WhatsApp, Copy Link).
  - One-click links to Nate Mina's portfolio, TikTok, GitHub, LinkedIn, and YouTube channel.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Nate-Mina/DomInNATEly-Music-Gallery.git

# 2. Navigate to the project directory
cd DomInNATEly-Music-Gallery

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Build for Production

```bash
# Create an optimized production build
npm run build

# Preview the production build locally
npm run preview
```
