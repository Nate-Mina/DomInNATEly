# DomInNATEly's Music

Welcome to **DomInNATEly's Music** — a TypeScript-based project for music management and curation.

## Overview

This project is built with TypeScript and provides a foundation for music-related functionality and features.

## Tech Stack

- **Language**: TypeScript (98.8%)
- **Other**: 1.2%

## Getting Started

### Prerequisites

- Node.js (v16 or higher recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/Nate-Mina/DomInNATEly.git
cd DomInNATEly
npm install
```

### Development

```bash
npm run dev
```
