## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher recommended)
- npm, yarn, or pnpm

### Installation

```bash
git clone https://github.com/Nate-Mina/DomInNATEly.git
cd DomInNATEly
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
